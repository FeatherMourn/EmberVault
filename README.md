# EmberVault

EmberVault is an independent research archive and wiki focused on understanding
the modding environment, runtime behavior, data structures, and development
possibilities of Enshrouded. The research in this repository is documented with
its methods, evidence, limitations, successful results, and failed or blocked
experiments so that other researchers can review the work and continue it.

## Scope and version

Unless a record says otherwise, the research documented here was conducted
against Enshrouded version **1.0.0.3**. Results may change as the game, loaders,
mods, or supporting tools evolve.
