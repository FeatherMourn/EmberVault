# EmberVault Game Map · Version 1.0

This directory contains the curated, reproducible research map for the current Enshrouded build. Raw KFC files are intentionally not stored here; they can be exported locally and matched using the metadata and checksums.

## Contents

- `catalogs/` — curated resource, item, world, tuning, and type indexes.
- `reports/` — usefulness, localization, and audit reports.
- `probes/` — ShroudForge-format read-only probe packages.
- `adapters/` — adapter contracts and capability records.
- `methods/` — collection and validation methods.
- `metadata.json` — source, build, loader, and provenance information.
