API Sweep

A Lua runtime probe that reports the shape of the exposed API surface once, on a one-second update schedule.

Programming profile

  • Language: Lua.
  • Entry point: src/mod.lua.
  • Execution model: returns a table with update_interval_ms = 1000 and an on_update callback.
  • One-shot guard: a local reported flag prevents repeated output after the first successful update.
  • Error handling: the helper wraps every lookup in pcall and records either the returned type or an error string.

What the code checks

It checks runtime types, type enumeration, ECS registry and component access, native-function listing, operations, services, overrides, game asset accessors, ShroudForge settings and logging, and io.export.

Explicit safety markers

The emitted lines state writes=not_attempted, native_calls=not_attempted, and world_data=not_requested. The probe logs its findings rather than claiming that every present function is usable.
