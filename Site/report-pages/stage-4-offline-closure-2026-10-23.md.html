## Remaining live gate

The first fresh v1.4.6 run after the module-cache correction produced a
current export and proved worker isolation: unsupported workers completed with
explicit statuses while slow workers timed out independently. The session was
not in a resolved private world, however, so `snapshot_generation` remained
unavailable and this run cannot close the smoke-test gate.

One valid private-world smoke run is still required before Stage 4 can be
marked 100% complete. It must use the active ShroudForge package at v1.4.6,
produce a fresh per-run export with a real session/snapshot generation, and
verify the same independent terminal statuses without an unrelated worker
suppressing the export. No write capability is involved.
