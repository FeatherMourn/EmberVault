KFC Resource File Identifiers

A compact public summary of the staged identifier census. The complete raw export remains in the local research archive.

What this report records

This report maps resource-file identifiers discovered in the Enshrouded 1.0 KFC export. It records 91,812 source records across 146 resource folders and 146 distinct identifiers.

Evidence and limits

This is static export evidence. It supports cataloging and cross-reference work, but it does not establish runtime availability, write access, or safe modification.

Provenance

Source: local KFC export captured for the EmberVault 1.0 snapshot. The full JSON and generated source page are intentionally retained locally rather than published with the public site.
