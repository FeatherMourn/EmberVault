API Capability Probe

A small Lua probe that checks whether selected global objects and functions exist, without traversing resources or accessing saves.

Programming profile

  • Language: Lua.
  • Entry point: src/mod.lua, declared by the package manifest.
  • Execution model: immediate bounded checks during module execution.
  • Safety primitive: each capability test runs inside pcall, converting thrown errors into recorded states.
  • Output: tab-separated text exported as embervault/api-capability-v1.tsv.

What the code checks

The source checks the types of game, game.assets, game.assets.get_resources_by_type, io, io.export, and pcall. It writes a schema version, probe ID, version, evidence state, collection status, and limitations before exporting.

Capability boundary

This is a presence probe. It does not call resource traversal, inspect payloads, enumerate entities, mutate state, access saves, or infer runtime behavior from a function’s existence.
