Field and Reference Probes

Inspects scalar fields, nested paths, template fields, reference values, and opaque payload boundaries.

Purpose

Determine which fields can be read safely and how references are shaped without assuming that a reference resolves to a usable entity.

Technical details

  • Input: bounded type and field targets.
  • Output: field paths, value states, value types, and unresolved-reference notes.
  • Writes: not attempted.
  • Limit: opaque or unresolved payloads remain unknown rather than being inferred.
