Probe family · Appearance and player state

Appearance and Player State

These probes investigate character schemas, appearance fields, local-player context, and possible ownership bridges. They are deliberately separated from mutation claims.

Probe breakdown

SCHEMA

Character Schema Probe

Reads character and appearance structure, including preset, body, hair, beard, color, and reference fields.

Capability: static or observed schema mapping.

OBSERVATION

Actor Appearance Probe

Looks for appearance data on actor-related surfaces and records available fields and shapes.

Limit: does not prove a live player target.

OWNER CONTEXT

Player Owner Context Probe

Tests whether a player or owner identity can be connected to runtime resources.

Result: identity bridge remains unresolved under the current environment.

GUARDED TEST

Appearance Write Probe

Performs a controlled no-op-style appearance write and restoration check.

Evidence: accepted readback is not proof of live ownership or supported mutation.
