Resource Type Probes

Inventories resource types and qualified names so catalogs and runtime observations can be compared using explicit type identities.

Purpose

Find resource classes, compare ShroudForge output with historical EML observations, and identify candidates for focused field probes.

Technical details

  • Input: runtime resource service and type-index data.
  • Output: type names, qualified names, counts, and source references.
  • Writes: not attempted.
  • Limit: a type census does not show that instances are live, owned, or writable.
