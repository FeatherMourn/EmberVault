# EmberVault site data

This directory is the organized public-facing data layer for the EmberVault archive.

- `capabilities.json` — canonical capability records.
- `mods.json` — probes, adapters, and research tools.
- `experiments.json` — reproducible investigations, including failed and partial results.
- `catalogs/` — curated canonical data copied from the build snapshot.
- `reports/` — selected evidence and historical findings.
- `provenance/` — source and collection context.
- `probes/` — selected reproducible probe packages.

The full working repository contains additional intermediate reports and local material. This site layer intentionally includes only curated, reviewable records and source artifacts suitable for public navigation.
