0001# Stage 4 Private-World Smoke Test Plan 0002 0003## Purpose 0004 0005Validate the corrected ShroudForge census worker package without changing saves, worlds, or unrelated mods. This is a read-only behavior test, not a native rebuild or ownership test. 0006 0007## Preconditions 0008 00091. Enshrouded and ShroudForge are fully closed. 00102. The active package is `EmberVault Census Workers`, version 1.4.5, classified as a ShroudForge client mod. 00113. The package manifest, root entry point, `src` entry point, and runtime worker source have passed offline validation. 00124. The current loader/runtime files have a timestamped rollback backup. 00135. The private-world boundary is confirmed; no write-capable probe is enabled. 0014 0015## Run sequence 0016 00171. Record the pre-run loader and package inventory, including hashes and enabled state. 00182. Launch through ShroudForge and load the private world. 00193. Remain in-world for up to 90 seconds. Do not restart during the observation window. 00204. Collect the newest `census-workers-v146-run-*.tsv`, the latest convenience export, reload result, and ShroudForge log. 00215. Match the export to the current run using `probe_version`, `worker_graph_version`, `run_count`, `snapshot_generation`, and `export_run_token`. 00226. If the identity does not match the current session, mark the run stale and stop interpretation; do not retry by guessing. 0023 0024## Pass criteria 0025 0026- A fresh per-run export is produced. 0027- The export contains a current run token and snapshot generation. 0028- Player, inventory-link, inventory-scan, and equipment workers each have an independent terminal status. 0029- Unsupported domains are listed explicitly rather than omitted. 0030- A slow or unsupported worker does not prevent other workers from exporting. 0031- No save/world files or unrelated package files change. 0032 0033## Failure handling 0034 0035- No export: classify as execution or package failure, not a data failure. 0036- Old export only: classify as stale-export rejection and stop. 0037- Crash or hang: stop immediately, restore the backed-up runtime, and preserve logs. 0038- Any unexpected write: stop, preserve evidence, and do not repeat until reviewed. 0039 0040## Exit 0041 0042The result is a Stage 4 smoke-test evidence report. Passing this plan closes the export-identity and worker-isolation gates; it does not prove the unsupported domain workers or enable any writes. 0043
