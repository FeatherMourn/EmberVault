0001# Loader Test Runner Outline 0002 0003## Scope 0004 0005The runner prepares isolated loader test cases and collects evidence. The 0006initial version must not modify the live installation, attach to a process, or 0007launch the game automatically. 0008 0009## Inputs 0010 0011- Source installation path 0012- Separate test-root path 0013- Test-case identifier from `controlled-loader-test-plan.md` 0014- Files and directories explicitly approved for that case 0015- Optional user-supplied launch command, disabled by default 0016 0017## Preparation steps 0018 00191. Verify source and test roots are different. 00202. Create a new timestamped case directory. 00213. Copy only approved files into the case directory. 00224. Record source and destination hashes. 00235. Validate configuration syntax and required files. 00246. Write a preparation manifest with the game build and case identifier. 00257. Require explicit confirmation before any game launch. 0026 0027## Collection steps 0028 0029After the user ends the test run, collect only: 0030 0031- proxy logs; 0032- EML logs; 0033- ShroudForge logs; 0034- Shroudtopia logs; 0035- passive module-load evidence supplied by the user or approved monitor; 0036- process exit status; 0037- post-run hashes and configuration diff. 0038 0039## Output record 0040 0041```json 0042{ 0043 "case": "A", 0044 "status": "prepared", 0045 "gameBuild": "unknown", 0046 "sourceRoot": "user-supplied", 0047 "testRoot": "isolated-case-directory", 0048 "approvedComponents": [], 0049 "preRunHashes": {}, 0050 "postRunHashes": {}, 0051 "runtimeEvidence": [], 0052 "limitations": [], 0053 "rollback": "discard-test-root" 0054} 0055``` 0056 0057## Stop conditions 0058 0059The runner must stop preparation or collection when: 0060 0061- the source and test roots resolve to the same directory; 0062- a requested file is outside the approved source root; 0063- a destination would overwrite the source installation; 0064- a required hash changes unexpectedly before launch; 0065- a test requests a write-capable probe; 0066- a user has not explicitly confirmed launch. 0067 0068## Initial cases 0069 0070- **Case A:** prepare Proxy + ShroudForge baseline. 0071- **Case B:** prepare EML-only test. 0072 0073The first implementation should prepare these cases and generate manifests; 0074manual launch and passive module observation remain separate controlled steps. 0075
