0001# ModLoader Proxy 1.1.0 x64 0002 0003## Short summary 0004 0005ModLoader Proxy is the active root chainloader used to keep one game-owned DLL entry point while loading multiple native plugins. It forwards the real system DLL exports and loads explicitly listed mod DLLs in a controlled order. 0006 0007## How it is built 0008 0009- `modloader-proxy.dll`: renamed to a supported root DLL name, currently `dinput8.dll`. 0010- `chainloader.ini`: controls forwarding, deferred loading, folder scanning, logging, and explicit load order. 0011- `supported_dlls.txt`: lists supported proxy names. 0012 0013The proxy can forward to one other proxy through `ForwardTo`, while ordinary native plugins are loaded from the `[Load]` list. Folder loading is non-recursive and alphabetical; explicit entries load first. 0014 0015## Compatibility rules 0016 0017- Only one root owner should be installed in the game directory. 0018- Standalone loaders such as Shroudtopia, Stat Sliders, ShroudHud Standalone, or AutoLootPlus cannot simply be listed as ordinary plugins unless their proxy behavior is explicitly supported. 0019- The active setup forwards to the original ShroudForge loader and explicitly loads Creative, XHL plugins, and the M182 panel. 0020- The archive documentation warns that this is intended for single-player or private server modding and should not be used with anti-cheat or public multiplayer. 0021 0022## Evidence level 0023 0024**Verified from archive:** configuration format, supported proxy names, forwarding model, load order, folder behavior, and stated multiplayer limitation. 0025 0026**Not verified in this audit:** compatibility with every standalone loader in the archive collection. 0027
