0001# Minimap and Weather Clock 0.5.12 0002 0003## Short summary 0004 0005This archive is the Sparkweave community fork of the Enshrouded Minimap. It combines a native `minimap_mod.dll`, Lua configuration, map assets, and Shroudtopia integration. It is not a standalone ShroudForge mod and requires the maintained Shroudtopia/WINMM loader pair. 0006 0007## How it is built 0008 0009- `mods/minimap_mod/minimap_mod.dll`: native renderer and integration layer. 0010- `mods/minimap_mod/src/mod.lua`: Lua-side configuration/runtime setup. 0011- `mod.json`: keeps the existing `minimap_mod` identifier and declares Shroudtopia settings. 0012- Map and icon assets: supplied terrain, fog-of-war, POI, player, marker, and weather resources. 0013- `realmap-provenance.json`: records map source, hashes, conversion, and alignment notes. 0014 0015The native side supports GPU terrain rendering with a CPU fallback. The Lua/configuration side controls visibility, position, orientation, markers, clock/weather display, zoom, and size. 0016 0017## Documented controls and defaults 0018 0019- F10 toggles the minimap. 0020- The default position is bottom-right and orientation is north-up. 0021- F9 and F11 decrease/increase size in the included configuration. 0022- The configuration also includes zoom keys, map markers, waypoints, pings, death markers, fog of war, weather, and clock options. 0023 0024## Loader compatibility and prior failure 0025 0026The README explicitly requires the maintained Shroudtopia and WINMM loader pair, which are not bundled. That explains why the mod did not populate when treated as an ordinary ShroudForge/proxy plugin. The previous active installation was removed after it interfered with the working setup; the archive remains available for research and is not active. 0027 0028## Evidence level 0029 0030**Verified from archive:** fork provenance, package layout, native DLL, required loader family, settings, hotkeys, GPU/CPU fallback, and map provenance metadata. 0031 0032**Not verified in this audit:** live rendering on the current game build, compatibility with the current ModLoader Proxy/ShroudForge chain, or whether the Shroudtopia/WINMM pair can be safely reintroduced. 0033
