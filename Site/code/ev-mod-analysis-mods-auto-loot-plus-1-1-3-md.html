0001# AutoLootPlus 1.1.3 0002 0003## Short summary 0004 0005AutoLootPlus is a native-loader mod with Lua/configuration content that automates pickup and optional ruin/container smashing. The 1.1.3 archive includes its README, configuration, item lists, manifest, and source files. It is not currently active in the ShroudForge setup. 0006 0007## How it is built 0008 0009- Root `dinput8.dll`: standalone loader entry point. 0010- `mods/auto-loot-plus/`: EML mod package with `mod.json`, Lua source, configuration, item lists, and templates. 0011- `dbghelp.dll`: required by EML according to the bundled README. 0012- The Lua/configuration layer defines pickup categories, ignored items, stack behavior, and menu settings; the native loader supplies the entry point and runtime integration. 0013 0014## Behavior documented by the archive 0015 0016- F8 opens the configuration menu. 0017- F9 toggles Auto Loot. 0018- Supports ground loot, resources, collectibles, plants/crops, corpses, chests, and containers. 0019- Optional auto-smashing of ruins. 0020- Supports larger stack behavior and configurable item lists. 0021- The bundled README states that the full version is intended for single-player and is not multiplayer-supported. 0022 0023## Version comparison 0024 0025Compared with the older 1.1.1 copy previously used, 1.1.3 documents fixes for over-collection, base-protection distance handling, world-load timing for smashing settings, ignore-item behavior, and false inventory-full indications. 0026 0027## Loader compatibility 0028 0029The archive expects to own the root `dinput8.dll`, so it cannot simply be placed beneath the current ShroudForge proxy without a verified compatible chain configuration. Before uninstalling, oversized stacks should be split into normal-sized stacks and the game should be saved after the mod is disabled.
