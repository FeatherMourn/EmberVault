0001# More Character Colors 1.1.0 0002 0003## Short summary 0004 0005More Character Colors is an EML/Lua pregame data patch. It unlocks hidden vanilla colors and adds skin, eye, eyebrow, and hair swatches without a native DLL or runtime hook. 0006 0007## How it is built 0008 0009- `mod.json`: declares patch/export capabilities and version 1.1.0. 0010- `src/mod.lua`: edits character customization and barber data before the game starts. 0011- Requires EML's `dbghelp.dll` beside the game executable. 0012- Uses stable named IDs so saved characters can retain their selected colors. 0013 0014## Documented limits and safety logic 0015 0016- Skin and eye lists are capped at 55 entries; the README states that 65 can crash at startup. 0017- Hair gradients are capped at 32 total entries. 0018- The Lua file includes gamma settings and a reference hair preset for visual calibration. 0019- Removing or renaming a color can make characters using it fall back to a default. 0020- Other players need the mod to see the added colors in multiplayer. 0021 0022## Version 1.1.0 changes 0023 0024The archive adds another fantasy-themed set of colors and retains the 1.0 layout and allocator-limit safeguards. It is a newer and more complete package than the earlier documented copy. 0025 0026## Loader compatibility 0027 0028This is an EML package rather than a native proxy DLL. It should be installed under the EML/ShroudForge mod directory with the existing EML runtime, not added to the proxy's native DLL list. 0029 0030## Evidence level 0031 0032**Verified from archive:** manifest, Lua source, EML requirement, feature list, data limits, save-ID behavior, multiplayer note, and version history. 0033 0034**Not verified in this audit:** live character-creation behavior on the current installation. 0035
