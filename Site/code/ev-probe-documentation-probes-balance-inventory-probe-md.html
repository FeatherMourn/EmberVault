0001# Balance inventory probe 0002 0003This probe is restricted to local or private-world research. It is read-only and does not alter saves, resources, recipes, progression, or network state. 0004 0005## Inventory scope 0006 0007- ItemInfo IDs, GUIDs, debug names, stack limits, durability and displayed-stat references. 0008- Recipe inputs and outputs, quantities, workshop IDs, category references, cooking flags, and upgrade flags. 0009- Workshop and station identifiers, including verified ItemInfo fallback names. 0010- Progression and unlock references where exposed by the static catalogs. 0011- Provenance for every value: static KFC evidence, cache evidence, runtime observation, or inference. 0012 0013## Output rules 0014 0015The adapter should emit a compact TSV or JSON catalog suitable for balance review. It must preserve unresolved and inferred values, never guess missing IDs, and keep raw game files outside the repository. 0016 0017## Explicit boundary 0018 0019This inventory does not patch files, alter live memory, bypass protections, automate multiplayer actions, or provide an advantage in online play. Any later balance change should be a separate, user-reviewed local mod with backups and an explicit target list. 0020
