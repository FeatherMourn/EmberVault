0001# M182 Client 2.0 0002 0003## Short summary 0004 0005M182 Client is an EML/native administrator panel for creature spawning, item/stat editing, zones, bases, teams, PvP, and player utilities. It combines `M182_Panel.dll`, EML configuration, two Lua patch mods, and a separate `dbghelp.dll` dependency. 0006 0007## How it is built 0008 0009- `M182_Panel.dll`: native panel and client/server communication layer. 0010- `dbghelp.dll`: EML/native support dependency. 0011- `eml.json`: EML runtime options. 0012- `m182_native.json`: native feature and hotkey configuration. 0013- `m182_panel.json`: panel limits. 0014- `mods/m182_spawn_variants`: Lua patch/export package for stronger creature variants and enemy-list export. 0015- `mods/zz_m182_item_stats`: Lua patch package applying item and balance values selected in the panel. 0016 0017The panel writes or updates the Lua data used by the item-stat mod, and it can communicate with a server through hidden chat commands described in the README. 0018 0019## Documented features 0020 0021- Insert opens the panel. 0022- F8 opens the creature spawner; F7/F6/F5 are diagnostic or watch functions. 0023- Creature spawns can respawn near players and remain idle when nobody is nearby. 0024- Items can be granted with level, rarity, amount, and custom stats. 0025- Includes admin powers, PvP controls, zones, protected bases, teams, and server settings. 0026- Local play applies changes directly; dedicated-server use requires the separate server package. 0027- Borderless window mode is required for the overlay panel to appear reliably. 0028 0029## Loader compatibility 0030 0031The package README expects its files to be copied into the game root, which means it is not a simple Lua-only mod. Its native DLL and `dbghelp.dll` must be considered part of the loader chain. The current setup already loads `M182_Panel.dll` through the proxy chain, but the archive's standalone installation instructions should not be applied over the working ShroudForge files without a backup and compatibility check. 0032 0033## Risks and limitations 0034 0035- It can change persistent item, player, world, and server state; it is not a read-only tool. 0036- Server chat transport can expose administrative actions to server logs or other players if the server-side package is not configured correctly. 0037- Spawn counts and server requests can create load, especially with many active spawns. 0038- The archive includes `m182_spawn_variants`, but that folder was previously removed from the active setup and preserved separately. 0039 0040## Evidence level 0041 0042**Verified from archive:** package contents, manifests, configuration keys, hotkeys, feature descriptions, local/server distinction, overlay requirement, and uninstall list. 0043 0044**Not verified in this audit:** current server-package compatibility, every panel feature on the present game build, and whether the standalone archive loader can coexist directly with the current proxy chain. 0045 0046## Current compatibility status 0047 0048The user reports that M182 does not currently work in the active ShroudForge setup. It is therefore a failed integration at present, not a confirmed working proxy plugin. The next investigation should inspect the M182 log and proxy load result separately to distinguish DLL loading, EML dependency, overlay-window, and panel-configuration failures. 0049
