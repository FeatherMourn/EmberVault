0001# EmberVault Broad Runtime Census Roadmap 0002 0003## Objective 0004 0005Build a reusable, read-only discovery framework that catalogs what the current Enshrouded runtime represents, exposes, permits, and persists through ShroudForge and the private EmberVault fork, with EML retained only as historical/static corroboration alongside reflection data and backed-up save copies. 0006 0007Every result must distinguish represented, discoverable, readable, writable, persistent, unsupported, scanning, stale, blocked, or unknown. telemetry follow this milestone because they improve maintenance and diagnosis of the provider runtime. 0019 0020## Advanced architecture order 0021 002233. **Capability graph** â€” model
