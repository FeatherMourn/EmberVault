0001# Isolated Enshrouded Test Install Checklist 0002 0003## Purpose 0004 0005Create a complete test installation for Case A while preserving the current 0006installation as the known-good baseline. 0007 0008## Suggested paths 0009 0010```text 0011Baseline: H:\SteamLibrary\steamapps\common\Enshrouded 0012Test copy: H:\SteamLibrary\steamapps\common\Enshrouded-Test 0013Case staging: H:\enshroudedresearch\test-runs\case-A 0014``` 0015 0016## Before copying 0017 0018- Close Enshrouded. 0019- Confirm no Enshrouded process is running. 0020- Confirm the destination does not already contain an unrelated installation. 0021- Confirm sufficient free space on the H drive. 0022- Record the baseline game build and current loader inventory. 0023 0024## Copy verification 0025 0026- Copy the complete game directory, including the executable, `.dat` files, 0027 `.kfc` files, resources, and existing mod-related directories. 0028- Confirm the destination contains `enshrouded.exe`. 0029- Confirm the destination contains the expected numbered data files and KFC 0030 resources. 0031- Compare file counts and total size with the baseline. 0032- Generate a destination-only hash manifest for the loader artifacts. 0033 0034## Case A preparation 0035 0036- Keep the baseline loader files in the destination unless the test profile 0037 explicitly replaces them. 0038- Configure only the ModLoader Proxy and ShroudForge baseline chain. 0039- Disable EML, Shroudtopia, and unrelated experimental components for the first 0040 run. 0041- Preserve the destination's original files in a test-copy backup directory. 0042- Capture a fresh pre-run configuration and hash manifest. 0043 0044## Manual run 0045 0046- Launch only the test installation. 0047- Observe the process passively. 0048- Do not attach a debugger or inject a diagnostic module. 0049- Stop the run on a crash, hang, repeated loader loop, or unexpected file 0050 mutation. 0051- After exit, copy proxy and ShroudForge logs into the Case A evidence folder. 0052 0053## Cleanup and rollback 0054 0055- Do not merge files back into the baseline installation. 0056- Discard or quarantine the test copy if it becomes inconsistent. 0057- Preserve the evidence manifest and logs even if the run fails. 0058
