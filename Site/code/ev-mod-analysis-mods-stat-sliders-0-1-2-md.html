0001# Stat Sliders 0.1.2 0002 0003## Short summary 0004 0005Stat Sliders is a standalone native `dinput8.dll` plugin. It pattern-scans the game, hooks internal systems, and adds configurable sliders for player, combat, movement, resource, experience, and stack-related values. It is not an EML or ordinary ShroudForge Lua mod. 0006 0007## How it is built 0008 0009- Root `dinput8.dll`: loader and native plugin in one file. 0010- `Alternative_powrprof/powrprof.dll`: alternate proxy component included by the package. 0011- Embedded strings show internal hook names, validation checks, settings labels, and configuration parsing. 0012- It uses signature matching and call-site validation; failed validation disables affected functionality rather than blindly patching. 0013 0014## Documented or embedded behavior 0015 0016- Adds a Stat Sliders section to the game's Game settings when its UI hooks succeed. 0017- Supports solo-only operation by default, with a co-op mode option. 0018- Detects other players and can disable itself while they are present. 0019- Applies values when entering a world and re-applies them after session changes or respawns. 0020- Exposes values such as health, stamina, mana, regeneration, damage, resistances, critical stats, movement, experience, resource stacks, and mining damage. 0021- Dedicated-server mode uses an INI configuration and applies values to every player without a local menu. 0022 0023## Why it did not load in the current setup 0024 0025The archive's `dinput8.dll` is itself a root loader and expects to control the game's entry point. Placing it as a normal proxy-listed plugin does not satisfy that design, which explains why no settings section appeared. It also cannot safely replace the current working ModLoader Proxy/ShroudForge root without a separate loader profile. 0026 0027## Risks and limitations 0028 0029- Native signatures are version-sensitive and can disable the core or UI when the game changes. 0030- The mod changes gameplay and player attributes; it is not read-only. 0031- Co-op behavior is intentionally restricted or disabled unless explicitly enabled. 0032- Running more than one copy is detected and causes one copy to remain inactive. 0033 0034## Evidence level 0035 0036**Verified from archive:** standalone loader layout, alternate proxy component, embedded hook names, validation behavior, settings labels, solo/co-op handling, and dedicated-server behavior. 0037 0038**Not verified in this audit:** successful loading through the current proxy chain or menu availability on the current installation. 0039
