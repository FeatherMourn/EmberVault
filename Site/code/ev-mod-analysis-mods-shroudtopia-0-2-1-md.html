0001# Shroudweave Shroudtopia 0.2.1 0002 0003## Short summary 0004 0005Shroudtopia is a standalone Windows x64 compatibility loader used by the minimap and related native mods. This community build includes both `winmm.dll` and `shroudtopia.dll`, keeps an existing JSON configuration, and adds a compatibility change for Creative Mode 3.0.0. 0006 0007## How it is built 0008 0009- `winmm.dll`: root WinMM proxy. 0010- `shroudtopia.dll`: native loader and mod-discovery layer. 0011- `shroudtopia.json`: user configuration, intentionally omitted from this archive so an existing configuration is not overwritten. 0012- Example JSON: defaults to an empty mod list. 0013- Build metadata and SHA-256 manifest: identify the build and packaged DLLs. 0014 0015The loader discovers supported native manifests and skips Flame-owned or malformed manifests before attempting to load them. This is the compatibility mechanism that lets Creative Mode use its separate Flame/proxy path. 0016 0017## Compatibility notes 0018 0019- Requires both root DLLs and therefore competes directly with other root loader systems. 0020- The release notes specifically claim compatibility with Creative Mode 3.0.0 and in-game validation of the minimap's visibility and controls. 0021- The Minimap archive is installed separately under `mods/minimap_mod`. 0022- The package does not include Creative Mode or the minimap itself. 0023 0024## Why it is not active 0025 0026The current installation uses ModLoader Proxy as the root owner and forwards to ShroudForge. Installing Shroudtopia would replace or compete for the root `winmm.dll`/loader path, so it was rolled back previously. The archive should be treated as an alternative loader stack, not layered on top of the working ShroudForge chain without a dedicated backup and test profile. 0027 0028## Evidence level 0029 0030**Verified from archive:** required DLLs, configuration policy, manifest filtering behavior, Creative compatibility claim, minimap relationship, validation scope, and backup instructions. 0031 0032**Not verified in this audit:** coexistence with the current ModLoader Proxy chain or compatibility with all active native plugins. 0033
