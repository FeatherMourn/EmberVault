0001# Creative Mode 3.0.0 0002 0003## Short summary 0004 0005Creative Mode is a native ShroudForge/Flame plugin with a large version-specific symbol and signature database. It adds creative building and gameplay utilities by locating internal game functions and data structures at runtime. The archive is more invasive and version-sensitive than a normal Lua or EML mod. 0006 0007## How it is built 0008 0009- Root `dinput8.dll`: bundled standalone loader entry point. 0010- `mods/creative/creative.dll`: native plugin. 0011- `mod.json`: declares the Flame plugin as Creative Mode version 3.0.0. 0012- `items.json`: defines custom or restored creative items and placement metadata. 0013- `sigs/`: version-specific signature and offset databases. 0014- `symbols/`: JSON descriptions of internal game systems, including input, player mode, crafting, inventory, map, movement, and server functions. 0015 0016The symbol files show that the plugin uses pattern scanning and documented offsets rather than relying only on fixed addresses. It still depends on the target game build matching the supplied signatures. 0017 0018## Observed capabilities 0019 0020The archive contains symbols for creative-related systems including item and recipe access, player mode changes, menu detection, movement/input data, crafting requests, server player permissions, map functions, and UI messages. `items.json` contains custom item definitions such as production-place entries and placement metadata. 0021 0022## Loader compatibility 0023 0024This archive includes its own root `dinput8.dll`, so it is a loader package, not just a DLL that can safely be dropped into the current proxy chain. The working ShroudForge setup uses the extracted Creative plugin and its native DLL under the existing proxy arrangement rather than replacing the root loader. The bundled Flame manifest should not be assumed to load correctly through ShroudForge without the compatibility arrangement already documented in the installation notes. 0025 0026## Risks and limitations 0027 0028- Native signature scanning can fail after a game update. 0029- The archive contains client and server-oriented symbols, so multiplayer behavior requires separate validation. 0030- Creative features may write gameplay, inventory, or world state; this is not a read-only diagnostic mod. 0031- The root loader must not be swapped while the current ShroudForge chain is working. 0032 0033## Evidence level 0034 0035**Verified from archive:** package layout, version, native DLL, Flame manifest, item definitions, signature files, and symbol coverage. 0036 0037**Not verified in this audit:** every menu or feature in the current game build, multiplayer behavior, and whether the bundled standalone loader can coexist directly with the current ModLoader Proxy chain. 0038
