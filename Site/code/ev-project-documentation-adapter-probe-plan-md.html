0001# Adapter and Probe Plan 0002 0003This plan defines how EmberVault will map Enshrouded through ShroudForge and 0004its Lua surface. EML references are historical/static compatibility evidence 0005only; they are not live fork targets. Probes are read-only by default; adapters translate 0006verified data into stable, build-aware contracts. 0007 0008## Adapter types 0009 0010| Adapter | Purpose | Initial scope | 0011|---|---|---| 0012| Manifest adapter | Normalize package identity, capabilities, and dependencies | ShroudForge manifests; EML only as historical input | 0013| Resource adapter | Convert runtime resource records into typed EML records | ItemInfo, recipes, materials, tuning | 0014| Schema adapter | Preserve field types, names, relationships, and provenance | KFC/reflection-derived schemas | 0015| Export adapter | Convert read results into CSV, JSON, or catalog entries | Bounded, read-only exports | 0016| Evidence adapter | Bind logs and outputs to build, probe, and package identity | Structured markers and freshness | 0017| Configuration adapter | Read supported mod configuration without mutation | Defaults, current values, validation state | 0018| UI/action adapter | Map safe actions and status reporting to ShroudForge UI | Diagnostics and probe triggers | 0019| Snapshot adapter | Convert recorded world data into previewable metadata | Offline snapshots only initially | 0020| Compatibility adapter | Compare package/runtime/build requirements | ShroudForge baseline and staged bridge; historical EML records remain labeled | 0021| Dependency adapter | Resolve required and optional package relationships | Fail-closed validation | 0022 0023## Probe types 0024 0025| Probe | What it investigates | Safety level | 0026|---|---|---| 0027| Loader probe | Discovery, manifest parsing, enable/disable behavior | Read-only | 0028| Lifecycle probe | Initialization, startup, shutdown, and failure order | Read-only | 0029| Logging probe | Structured markers, timestamps, build identity, evidence import | Read-only | 0030| Asset-type probe | Which resource types can be enumerated | Read-only | 0031| Asset-field probe | Which fields can be read and their runtime types | Read-only | 0032| Export probe | Whether bounded results can be written to an export file | Read-only game access | 0033| Configuration probe | Supported configuration surfaces and validation rules | Read-only | 0034| UI/action probe | Action registration, status display, and callbacks | Read-only | 0035| Dependency probe | Required/optional dependency resolution and rejection | Read-only | 0036| Snapshot probe | Preview, bounds, counts, and provenance for recorded data | Offline/read-only | 0037| World-context probe | Whether a valid current-build world context exists | Read-only | 0038| World-read probe | Bounded voxel, entity, prop, or cursor queries | Read-only; current-build evidence required | 0039| Multiplayer probe | Authority, session role, and replication visibility | Read-only; separate test world | 0040| Mutation probe | Whether a guarded write path exists | Deferred; explicit approval required | 0041 0042## Investigation order 0043 00441. Loader and lifecycle. 00452. Logging and evidence import. 00463. Asset types and fields. 00474. Export and configuration. 00485. UI/actions and dependencies. 00496. Offline snapshot and blueprint metadata. 00507. Current-build world context and bounded reads. 00518. Multiplayer observation. 00529. Guarded mutation only after backup, permission, readback, and rollback gates. 0053 0054## Promotion rules 0055 0056- A probe result must identify the game build, loader version, package version, 0057 and evidence level. 0058- A catalog or reflection entry is not proof of live access or writability. 0059- Every adapter must declare permissions, dependencies, failure behavior, and 0060 unsupported operations. 0061- Failed and skipped probes are recorded as useful boundary evidence. 0062- No mutation probe is promoted from design to execution without explicit 0063 approval and a recoverable test environment. 0064
