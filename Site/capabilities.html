Capabilities

A subject index for what Enshrouded data and the ShroudForge runtime may expose. Each capability is separated into static evidence, runtime observation, verified behavior, limitations, and unresolved questions.

Capability groups

Inventory and item state

Inventory schemas, equipment links, item instances, and the unresolved player-ownership bridge.

Runtime API surfaces

Observed services, resource types, fields, references, and the boundary between API presence and usable backend access.

Blueprint and building data

Readable blueprint resources and configuration fields, without a claim of live voxel writes or persistence.

Localization

Localization tags and the blocked EML export path, clearly marked as an environment limitation.

Evidence boundary

Static catalogs prove that a type or relationship exists in captured data. Runtime reports prove only what was observed in a particular build and environment. A capability is not promoted to verified behavior merely because a field, API name, or probe exists.
