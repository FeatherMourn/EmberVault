Loader conflict analysis

What collisions and repeated load events were visible in the local test environment?

Status: ObservedEvidence: Static + runtime logsBuild: UnknownScope: Local installation

Inputs

The conflict report correlated a static loader inventory with imported runtime events. It recorded 29 artifacts and 284 runtime events.

Observed patterns

  • Seven entry-point collision groups were reported.
  • Twenty-two repeated-load events were reported.
  • There were 119 activation attempts and 119 activation skips.
  • Collisions included dinput8.dll, dbghelp.dll, kfc-runtime.dll, shroudforge-runtime.dll, winmm.dll, and embedded WebView dependencies.

Interpretation boundary

This is environment-specific evidence.

The report’s game-build field is unknown, and the inventory includes backups, pending updates, and installed artifacts. It cannot establish universal compatibility or identify one guaranteed load order for every installation.

Next step

Repeat the scan on a clean, build-identified installation and separate active files from backups and pending-update paths before comparing runtime behavior.
