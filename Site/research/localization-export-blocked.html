Localization export blocked

Why did the localization inventory probe fail to produce an export?

Status: BlockedEvidence: ObservedBuild: 1.0Runtime: EML profile

What was attempted

The localization inventory probe was installed and the game reached the main menu. The test was intended to inventory localization data through the active EML export path.

What happened

No inventory export was produced.

The ShroudForge state reported the EML resource service unavailable, while the EML launch record reported exports disabled.

What this does not prove

This is not a negative result about localization data itself. It does not establish that localization inventory is impossible; it establishes that this particular EML runtime/export profile did not execute the probe path.

Next step

Retain the probe for a compatible EML profile and repeat the export test. Preserve the runtime profile and launch evidence so the failure can be compared directly.
