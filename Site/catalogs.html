Library category · Structured evidence

Catalogs: the static data layer.

Catalogs are curated snapshots of Enshrouded data. They help identify resources, fields, names, relationships, and candidates for runtime testing. They do not, by themselves, prove that a value can be changed in a live session.

Version boundary: These catalogs are associated with Enshrouded 1.0.0.3 and source build 39026384728. Treat them as build-specific evidence and revalidate after updates.

How to use a catalog

Catalog evidence is a starting point.

Use a catalog to form a question, identify a candidate resource or relationship, and choose a bounded probe. Then compare the static record with the runtime result and document any mismatch.

Evidence boundary

  • Static: present in captured data.
  • Observed: supported by a particular run or transformation.
  • Runtime: requires a matching probe/report.
  • Unknown: requires further testing.
